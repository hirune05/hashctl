# hashctl

A small SHA-256 CLI and HTTP service for practicing deployment to Kubernetes.

## Exercise checkpoints

1. Stream a file into a SHA-256 calculation.
2. Expose the calculation through a local CLI command.
3. Add an HTTP server and remote CLI command.
4. Containerize the service.
5. Deploy it to kind with Kustomize.
6. Diagnose intentionally broken deployments.
